mizrab is a music player built on basalam: a terminal application written in the [Salam](https://github.com/SalamLang/Salam) programming language.

> **Status: audio engine, playback controller, library scanner and app shell.** The [audio engine](/audio-engine) exists: it decodes MP3, FLAC, WAV and OGG, streams them through a lock-free ring buffer to miniaudio's playback callback, and runs headless on miniaudio's null backend, where its tests exercise it. The [playback controller](/playback-controller) above it owns the state, the commands and the queue. The binary runs both: a bare `mizrab` with stdin a terminal opens the [app shell](/app-shell), where `space`, `n` and `p` are bound to play/pause, next and previous. With stdin not a terminal it prints its usage block and exits 0, which is what every script and the harness's smoke checks see. It also runs the [library scanner](/library): `mizrab --scan ROOT...` walks the roots, reads tags and writes a JSON index. It reads a [config file](/configuration) at startup, and answers `--version` and `--help`. The shell is not finished: it binds six keys, and `:` and `/` record the request and open nothing yet.

The playback controller owns the state machine and the queue. The [audio engine](/audio-engine) page and the [playback controller](/playback-controller) page are the two findings for playback; the [app shell](/app-shell) page covers the interface it drives, and the [library](/library) page covers the scanner and its index.

Build it with [install](/install), then see the [configuration](/configuration), the [make targets](/make-targets), the [test harness](/tests) and the [repository layout](/repository-layout). To work on mizrab, read [contributing](/contributing); the source, issues and releases live on [GitHub](https://github.com/curedbylethe/mizrab).

## Built on

- [**basalam**](https://github.com/curedbylethe/basalam) — a retained-mode terminal UI library for Salam. It comes from Salam's package registry at `v0.3.2`, pinned in `salam.lock`.
- [**Salam**](https://github.com/SalamLang/Salam) — the language, compiler and standard library mizrab is written in.

The player binary imports the Salam standard library (`conv`, `flag`, `os`) plus its own `commands`, `config`, `library`, `ui` and `player` packages, and links the third C object, `build/library_shim.o`; basalam arrives through `ui/`. The `library` package additionally uses the `audio.tag` and `audio.flac` readers pinned in `salam.toml`, plus the standard library's JSON, crypto and filesystem packages. The audio engine uses `atomic`, `mem`, `sync` and `thread`, and the binary reaches it through `player/`, which it includes.
