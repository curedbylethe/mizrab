mizrab is a music player built on basalam: a terminal application written in the [Salam](https://github.com/SalamLang/Salam) programming language.

> **Status: scaffold.** The binary answers `--version` and `--help` and prints its usage when invoked bare. There is no playback, no library scanning and no user interface yet; those land in later issues. A spike under `spike/` proved that a Salam function can serve as miniaudio's data callback and fill f32 frames on Core Audio; the engine itself is not written ([the spike's verdict](/spike-miniaudio#verdict)).

Build it with [install](/install), then see the [make targets](/make-targets), the [test harness](/tests) and the [repository layout](/repository-layout). To work on mizrab, read [contributing](/contributing).

## Built on

- [**basalam**](https://github.com/curedbylethe/basalam) — a retained-mode terminal UI library for Salam. It is vendored at `vendor/basalam` and pinned to the `v0.2.0` release tag, by the commit that tag points at.
- [**Salam**](https://github.com/SalamLang/Salam) — the language, compiler and standard library mizrab is written in.

The player currently imports only the Salam standard library (`flag`, `os`) plus its own `commands` package; the basalam include arrives with the application layer. The spike also imports `conv`, `math`, `mem` and `sync`.
